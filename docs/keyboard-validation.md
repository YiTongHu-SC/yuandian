日期：2026-10-19，Asia/Shanghai。本轮只调整自由画布的键盘操作；画布 v1、存储键、JSON 和 MCP 接口不变。

## 自动检查

Windows `npm run verify` 的静态检查与 243 项 Node 测试全部通过。新增纯计算与模型测试覆盖四方向、偏轴候选、测量高度、无候选及稳定选择，独立同级、多父与环、容量不足整批拒绝，以及兼容 JSON 回导。模型测试不能替代下列页面操作。

## GPT 内置浏览器

使用独立来源 `http://127.0.0.1:4197/` 与虚构内容，不清空站点数据，未使用 Edge 或独立无头浏览器。

- 选中卡片后，右、下、左、上依次切换四张按方形摆放的卡片，选择与实际焦点一致；上方没有候选时停留。编辑中的左箭头只移动文字光标，不切换卡片。
- 编辑中 Ctrl+Enter 保存原卡片并进入新独立同级卡片；从选中分支按 Ctrl+Enter 新增同级，原父卡片分别连到两个分支。均只新增一张，位置在当前卡片下方。
- Enter 从选中进入编辑，编辑中 Enter 换行；Esc 退出编辑、保留卡片焦点并显示已保存。选中及编辑中的 Tab 都保留新建相连分支的行为。
- 撤销同级文字及创建后，从四卡两线回到三卡一线；重做恢复四卡两线。删除同级卡片后撤销，卡片与其父连线一并恢复。
- 等待已保存后刷新，四张卡片、多行文字与两条连线保留。真实导出 JSON 后从文件菜单预览并追加回导，生成四卡两线副本，原画布保留。文件菜单内的方向键没有切换画布卡片。
- 最新页面控制台无警告或错误。代码复核另修正容量不足时的焦点回落：保留原卡片选择、归焦并保存已有编辑。

多父与环、容量边界由纯模型与代码复核覆盖，未在页面造满 300 张卡片；未验证 macOS 实机、中文输入法合成期间按键及移动端键盘。未改旧六步入口或 MCP 授权逻辑，不将历史 MCP 验收计作本轮结果。线上发布结果以对应提交的 Actions 与本轮线上检查为准。
