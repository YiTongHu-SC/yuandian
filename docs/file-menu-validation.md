# 轻量文件菜单验证

日期：2026-10-19，Asia/Shanghai。环境：Windows、Node.js 24.14.0、Codex 内置浏览器。

## 本轮改动

- “文件”改为顶栏轻量菜单，直接提供导出当前画布、备份全部画布、导入 JSON；导出立即下载并关闭菜单，不再打开文件弹窗。
- 原生文件选择后，在同一菜单内显示文件名、追加摘要、确认和取消。读取、格式、大小及容量错误也留在菜单内；校验失败不允许追加。
- 取消、Esc、外点及打开其他菜单会清除未确认候选，并使在途读取失效；同一个文件可再次选择。Esc 返回文件按钮，追加失败返回导入按钮。
- 文件菜单打开时隔离画布删除与撤销快捷键。选择文件、读取和预览期间收到另一页更新，继续暂停覆盖并提供原有副本恢复。
- 存储键、v1 格式、模型校验、追加导入及旧六步工具保持原样，不需要数据迁移。

## 自动检查

`npm run verify` 通过静态检查与全部 66 项测试，包含模型导入导出、旧 v1 兼容、ID 冲突重映射、无效 / 超限导入不改变原工作区、异常存储与跨页写入保护。JavaScript 语法、入口资源和文档本地链接正常；`git diff --check` 通过。

本轮仅调整自由画布的界面和事件，不修改模型或引入依赖。异步文件读取保留序号校验，关闭、取消与重新选择均使旧序号失效；代码复审覆盖这一逻辑。

## 浏览器实测

在独立源 `http://127.0.0.1:4189/` 使用虚构卡片和生成的 v1 夹具；未操作正式源 `http://127.0.0.1:4176/` 的真实内容，未清空浏览器存储。

| 路径 | 实测结果 |
| --- | --- |
| 轻量菜单 | 文件菜单无模态遮罩；与画布菜单互斥，外点关闭；取消、关闭再打开不残留旧摘要 |
| 当前画布导出 | 从未结束的文字编辑直接打开菜单并导出，真实下载文件包含最新文字；下载后菜单关闭、焦点返回文件按钮 |
| 全部备份与回导 | 下载包含两张画布的完整备份，再经真实文件选择器追加；原有两张保留，总数变为四张。当前画布单独下载回导也成功 |

| 跨页冲突 | 一页停在导入预览，另一页编辑并保存；预览页提示保存暂停。本页确认追加仍未覆盖另一页；保留本页副本后，两边文字均可找到并恢复保存 |
| 窄屏 | 模拟 320×720 CSS 视口，长文件名与长画布名换行；菜单边界 x=12…308、y=121…546，页面无横向溢出 |
| 画布操作回归 | 编辑、延伸、跨分支连线、拖动正常；删卡后由三卡三线变为两卡一线，撤销恢复；等待保存再刷新，标题、文字、节点 ID、坐标、颜色、连线路径与 ID、视图变换均一致 |

## 验证边界

窄屏是桌面浏览器尺寸模拟，未验证真实触控设备和其他浏览器。原生文件选择器的操作系统级取消、实际慢文件乱序完成与文件读取失败未注入实测；相关取消 / 序号保护经代码复审。旧六步源码未改，本轮未重跑其完整界面流程；配额不足和不可用存储依赖现有模型回归，本轮未注入浏览器存储故障。
