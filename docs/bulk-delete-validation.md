- 创建 A、B、C、D 四张卡片，连接 A→B、A→C、C→D、C→A；框选 A、B 后，就地工具出现“删除所选”。点击后仅剩 C、D 与 C→D，未选内容和原坐标保留。
- 一次 Ctrl+Z 完整恢复四卡四线，节点 ID、文字、坐标及连线 ID、曲线路径与删除前的 DOM 读取结果一致；一次 Ctrl+Shift+Z 再次批删，结果与首次批删一致。工具栏撤销同样恢复整批。

- 框选四张后删除，显示空画布；一次撤销恢复四卡四线。等待保存后刷新，恢复的内容及坐标保留。

- 单卡菜单删除仍只删一张，撤销恢复；单独删线仍只删一条，撤销恢复。
