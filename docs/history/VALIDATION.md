## 页面实际操作

- 从空白新建独立问题，编辑目标；随手记生成假设，原始材料保留。
- 假设转验证，填写方法/指标/判据，生成具体行动；两个方向可并存，由用户设置本轮优先方向。
- 刷新后目标、验证和行动保留。
- 下载当前问题 JSON，使用真实文件选择器读回，预览后追加；原问题保留，副本的行动仍关联正确验证。
- 无效 JSON 显示错误、确认导入不可用，不改变原数据。
- 删除验证后行动保留、关联解除；撤销后恢复。
- 两条数据一条为空时不计算；填写为 10 和 5 小时后显示 15 小时，并保留“估计值演算”提示。
- 两标签页编辑后出现覆盖暂停提示；选择保留副本并合并后，另一页修改与本页新加的证据链接分别保留。
- 清理所有功能自检问题，只留默认空白问题；页面保存状态正常，控制台无错误；当前视口无横向溢出。
- `start.ps1 -NoBrowser` 首次启动、重复启动以及 `Start.cmd -NoBrowser` 均通过；复用同一服务，仅监听 `127.0.0.1:4176`。

页面预览见 [preview.png](../../assets/screenshots/preview.png)。验证数据仅用于功能检查，未作为任何用户的事实、收益或建议保留。

## 使用边界

自动保存依赖浏览器站点存储，不能代替 JSON 备份。跨页通过 Web Locks 协调本工具的写入，旧浏览器回退到保存前内容比较，不提供数据库事务保证。工具没有外部搜索或 AI 调用；数据、关联、标签、演算及填写完整度不认证结论正确。
