# 自由画布初版验证

历史记录：以下结果与命令对应初版目录，现行操作见 [开发与验证](../development.md)。

核验日期：2026-10-18。范围：本机 Windows 与 Codex 内置浏览器。

初版聚焦自由书写、摆放和连接，保留本机存储与备份；未新增 AI、自动分析、协作同步或复杂图形能力。

## 检查结果

- JavaScript 语法检查通过；14 项自由画布模型测试通过，旧版 30 项检查仍通过，共 44 项。
- 页面实测：双击节点原位编辑并输入多行；Tab 新建相连分支；按钮新增独立想法；编辑中点击颜色一次生效。
- 拖动节点后位置改变，连接随之重绘；跨分支连线成功，删除线条保留节点；删节点清理关联，撤销/重做恢复内容和连线。
- 空白处双击新增成功；拖空白平移、缩放、适配全部可操作。
- 下载真实 JSON 文件，使用文件选择器重新导入，生成新画布并保留原画布；更换为旧版不兼容文件后，导入按钮禁用，不误用上一个候选。
- 刷新前后五个示例节点的文字、坐标和颜色一致，三条连接保留，控制台无错误。
- 清理自检画布，只留下初始中心节点；[canvas-preview.png](../../assets/screenshots/canvas-preview.png) 为操作示例截图，内容不是对用户问题的分析结论。
- 启动脚本确认复用既有本机服务；旧入口 `guided.html` 和原始脚本保留，新版不读写旧版的存储键。

## 范围

撤销记录只保留在本次页面会话，平移和缩放不进入节点编辑撤销。自动保存属于当前浏览器与网址；JSON 备份用于迁移恢复。新旧工具的备份格式独立，初版不自动转换旧记录。移动端和其他浏览器未做完整实机验证。
