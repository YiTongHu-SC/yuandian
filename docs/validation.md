- 保留正式源 `http://127.0.0.1:4176`、两个存储键和 v1 数据格式；未清理、迁移或修改正式源的浏览器记录。

## 本机服务与限制

正式端口的旧 Python 进程已核验为本项目目录，随后切换到新的 Node 服务，继续使用 `127.0.0.1:4176`。重复运行启动脚本可复用同目录服务。新服务不公开 `.git`、`private`、`backups`、文档和测试；未停止无关进程。

本轮不改变 schema，没有数据迁移步骤。旧六步工具只验证加载、编辑保存与刷新，其余逻辑依靠保留的测试；未重复旧版全部界面流程。跨页冲突保留原实现并通过模型检查，本轮未重新执行完整双页冲突恢复。移动端、触控及其他浏览器未完整实机验证。

两个早期失败测试遗留的系统 TEMP 目录因自动审批策略未能清理，已保留；其中只有生成的测试夹具，不属于项目交付内容。
