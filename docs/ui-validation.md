# 极简卡片交互验证

日期：2026-10-18，Asia/Shanghai。环境：Windows、Node.js 24.14.0、Codex 内置浏览器。

## 本轮改动

- 顶栏保留产品名、唯一画布名称与管理菜单、新增卡片、撤销重做、保存状态、文件和帮助。移除画布内重复标题、英文装饰、版本标签、常驻教学与计数。
- 选中卡片后，就地提供编辑、延伸、连接和更多；颜色与删除收进更多菜单。选中连线后在点击附近提供删除。
- 首次打开空存储或新建画布时，直接编辑一张空卡。“写下任何想法…”只作占位提示；原有预填内容不改写。
- 编辑按钮 / Enter 将插入点放到末尾；双击文字尽量使用点击位置，浏览器不支持位置识别时退到末尾。进入编辑不再自动全选，编辑器内正常文字选择仍保留。
- 保留原有拖动、平移、缩放、Tab 延伸、撤销、JSON 追加导入及存储保护。文件导入导出仍使用原对话框，本轮没有实施文件轻菜单重构。

## 自动检查

`npm run verify` 的静态检查与 66 项测试通过：自由画布模型 16 项、历史与几何 9 项、旧六步模型与逻辑 30 项、工具 11 项。新增模型回归覆盖空文本保存恢复，以及旧 v1 预填文字、位置、颜色、标题、连线、标签与视图的读取 / 导出 / 追加导入兼容。

JavaScript 语法、两个入口的模块 / 样式引用及文档本地链接通过；`git diff --check` 通过。浏览器控制台未记录警告或错误。新旧存储键和 v1 字段未变，不需要迁移。新增连线点击锚点仅属于界面选择状态，不写入数据或 JSON。

## 浏览器实测

使用独立源 `http://127.0.0.1:4188/`、虚构卡片和生成的 v1 夹具；未重置浏览器存储，未操作正式源 `http://127.0.0.1:4176/` 的真实画布。

| 路径 | 实测结果 |
| --- | --- |
| 空卡起步 | 首次打开与菜单新建均立即聚焦空编辑器；实际值为空，占位文字不作为内容 |
| 编辑 | 多行输入正常；按钮进入已有文字时插入点在末尾，追加内容保留原文；双击进入时选区折叠，不全选全文 |
| 延伸与连接 | 编辑中按 Tab 连续延伸两张卡并建立关联；就地连接已有卡片成功，完成后退出模式；取消按钮可退出 |
| 换色与拖动 | 更多菜单换色生效；拖动后卡片与连线移动，工具条贴在卡片下方并保持正常字号 |
| 删除与撤销 | 删卡清理其两条关联，撤销恢复三张卡和三条线；重做再次删除，随后撤销可恢复；单独删线保留卡片 |
| 视图与保存 | 缩放、显示全部、空白平移正常；等待保存后刷新，标题、文字、节点 ID、坐标、颜色、连线路径与 ID、视图变换均与刷新前一致 |
| 多画布 | 菜单切换正常，新画布与已导入画布的撤销状态独立；唯一名称输入框可改名 |
| 菜单键盘 | 键盘打开画布菜单 / 卡片更多菜单后，Esc 分别返回画布菜单按钮 / 更多按钮，避免浮层关闭后丢失焦点 |
| JSON | 下载真实文件后经文件选择器回导，追加副本，三张卡、三条线与颜色保留；改选无效 JSON 后禁用导入 |
| 旧 v1 | 导入生成的旧格式文件后，“我想想清楚的问题”原文、两张卡的位置和配色、连线标签保留 |
| 边缘定位 | 卡片拖到右下边缘后，工具条与更多菜单在视口内向上避让；长连线中点位于屏外（x=-640）时，点击可见线段仍能找到删除入口 |
| 窄屏 | 模拟 320×720 CSS 视口，页面无横向溢出，顶栏、就地工具与展开菜单均位于视口内 |

示例截图：[极简卡片界面](../assets/screenshots/minimal-card-ui.png)，只含虚构内容。

## 验证边界

窄屏检查是桌面浏览器尺寸模拟，未完成真实移动设备、触控或其他浏览器验证。旧六步源码未改，本轮未重复其全部界面流程。跨页冲突与存储失败沿用原保护实现并通过模型回归，本轮未重跑完整双页冲突恢复。首次启动的自动聚焦不用于强行编辑已有空卡或原有预填卡片。
