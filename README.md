# 原点

**让思维可以自由生长。**

以卡片承载内容，用连线表达关系，尽量靠直觉完成书写、摆放和连接。原点追求极简的操作与界面，避免冗余功能，让用户自由组织自己的思考。

当前产品形态是自由思考画布，已支持文本卡片与连线，可在线使用或在本机运行。内容自动保存在当前浏览器，也可导出 JSON 备份。完整产品原则与当前边界见 [PROJECT.md](PROJECT.md)。

[在线使用](https://yitonghu-sc.github.io/yuandian/) · [GitHub 源码](https://github.com/YiTongHu-SC/yuandian)

在线版与本机版使用各自的浏览器站点存储，不自动同步。迁移时在来源端从“文件”导出 JSON，再在目标端选择“追加导入”；发布源码不会上传本机画布。在线版可通过独立 MCP 中继授权 Codex 访问当前浏览器、当前站点的全部画布，Pages 地址与本地数据位置不变。服务部署与当次验证状态见 [部署说明](docs/deployment.md)。

原生 HTML、CSS 和 JavaScript ES Modules，无构建步骤，无需安装前端依赖。

可选的 MCP 接入允许你授权 AI 客户端跨画布读取、编辑、新建和导出。普通画布可直接运行；使用 MCP 或运行完整测试前，在项目目录执行 `npm ci` 安装锁定的 Node 依赖。

## 启动

需要 Node.js 20 或以上版本。Windows 双击 `Start.cmd`，或在项目目录运行：

```powershell
.\start.ps1
```

固定入口：[http://127.0.0.1:4176/](http://127.0.0.1:4176/)。仅启动服务、不打开浏览器：

```powershell
.\start.ps1 -NoBrowser
```

开发时也可在终端前台运行服务，按 Ctrl+C 停止：

```powershell
npm start
```

服务只监听 `127.0.0.1`。Windows 启动脚本在后台运行服务，关闭网页后服务仍在；重复启动会核对当前项目目录并复用。端口被无关服务占用时会报错，不会结束其他进程。不要直接双击 `index.html`，浏览器需要通过 HTTP 加载 JavaScript 模块。

## 基本操作

- 新用户首次打开或新建画布时，从一张空卡片直接开始书写；“写下任何想法…”只是提示，不会写入内容。已有画布按原样打开。
- 单击选中卡片，双击原位编辑，也可点卡片旁的“编辑”或按 Enter 开始编辑；编辑中 Enter 换行，Esc 保存并退出编辑、保留选中，点击空白也可完成。进入编辑不再自动全选原文，可直接续写，内容继续自动保存。
- 非编辑状态下选中或聚焦卡片后，用上下左右键按画面位置切换，目标会显示在视野内；编辑时方向键照常移动文字光标。
- 双击空白或点顶部“＋卡片”，创建独立卡片；选中卡片后点就地工具中的“＋延伸”或按 Tab，创建并编辑相连卡片。
- 选中或编辑卡片时，按 Ctrl / ⌘ + Enter 在其下方空位新建同级空卡片并开始编辑，沿用当前颜色；同级卡片共享当前卡片的全部父卡片，无父卡片时则保持独立。
- 拖动卡片重新组合；默认拖空白平移画布。开启顶栏“框选”后，拖空白选择与选框相交的卡片；也可随时按住 Shift 拖空白框选。框选模式下，按住空格拖动或用鼠标中键拖动可平移画布。
- 框选后拖动任一所选卡片，整体移动并保持相对位置，一次撤销或重做恢复整组位置。点空白或按 Esc 取消多选；单击未选卡片切回单选，双击卡片进入该卡编辑。
- 多选时点就地工具中的“删除所选”，或在非编辑状态下按 Delete / Backspace，删除全部所选卡片及其所有入线、出线；未选卡片及其相互连线保留。一次撤销即可恢复完整卡片和相关连线，一次重做再次删除。配色仍按单张卡片操作，颜色的含义由你决定。
- 选中卡片后点其旁的“连接”，再点另一张卡片完成，连接完成后自动退出；可点“取消连接”或按 Esc 取消。点选线条后可就地删除连接。
- 卡片旁的“⋯”提供配色和删除；删除后可撤销，恢复卡片及其连线。
- 右下角缩放或 Ctrl / ⌘ + 滚轮；“显示全部”找回画布。
- Ctrl / ⌘ Z 撤销，Ctrl / ⌘ Shift Z 重做；撤销历史限本次页面会话。
- 顶部画布名称可直接改名，旁边的画布菜单提供切换、新建和删除；“文件”展开轻量菜单，直接导出当前画布、备份全部画布或导入 JSON。
- 顶部“帮助”可随时查看操作说明，画布不常驻操作提示或数量统计。

## AI 接入 · MCP

在线使用时，点顶栏“AI 接入”，选择权限与时长，再点“配对并授权”。首次将面板生成的固定 TOML 配置保存到 `~/.codex/config.toml` 的 `yuandian` 服务并让 Codex 加载，保留其他服务。已配置当前线上服务时，可在配对选项中粘贴已有配置以复用原凭据。原点不会自动修改客户端配置。

授权范围为当前浏览器、当前站点的全部画布。默认只读，可列举、读取和导出；编辑和新建需明确选择读写。授权时长可选“15分钟”“1小时”“永久（直到断开）”，默认“1小时”。选择永久后，刷新、重新打开页面或服务恢复会自动建立新的页面会话，保留你原先选择的只读或读写权限，直到点“断开授权”。重开时若浏览器能确认旧页已关闭，会直接恢复，无需等待旧会话的失联期限。关闭页面或失联期间暂停访问；页面重新在线后恢复，不提供离线读取或重放旧写入。仍有其他页打开（包括后台页）时，须明确改由当前页授权，不会静默接管。

本机版本先执行 `npm ci` 并启动服务，选择权限与相同的三个时长选项后“配对并授权”；永久授权的保留方式与线上相同。面板生成固定 stdio 的通用 `mcpServers` JSON，Codex 需按 [接入步骤](docs/mcp.md#codex-接入)转换。切换远程 HTTP 与本机 stdio 配置时，替换完整的 `yuandian` 条目，避免遗留另一种传输的字段。首次配置已保存不代表当前聊天已加载工具，需实际调用确认。

切换、新建、删除或追加导入画布后授权继续有效，后续新增画布也在范围内。范围不跨浏览器、站点或旧六步工具。AI 先用 `list_canvases` 获取画布 ID 和版本，`edit_canvas` 必须明确目标 `boardId`；成功保存才回执，卡片与连线的整批修改可在目标画布撤销。`create_canvas` 根据最新工作区版本新建空卡片画布，默认不切换当前画布；页面通知可撤销这次新增，已有内容改动时会拒绝删除。`export_canvas` 返回单张或全部画布的兼容 JSON，由 AI 客户端按需保存文件，不强制触发浏览器下载。

配对身份本身不能读取画布。未授权且没有永久授权意愿时，Codex 仍可发现工具，并收到 `needs_authorization`；在网页重新授权后即可继续。15 分钟与 1 小时授权仍在刷新、关闭、到期、异常失联或服务重启后失效，不自动续期，重新授权默认只读。无法取得旧页已关闭的锁证据，或旧会话来自更新前页面时，仍由失联机制兜底：远程中继最长 90 秒后清除活跃会话，本机桥为 10 秒；永久授权意愿保留，恢复连接后签名建立新会话。主动断开也会清除永久授权意愿，刷新或重开后不再恢复；主动取消配对、清理设备密钥后需重新配对。旧临时配置继续在失效后更新令牌，旧单画布授权不自动升级，已有配对也不会自动变成永久。

画布持久数据仍在浏览器，不建立账号或云同步。浏览器另在独立 IndexedDB 保存不可导出的配对私钥和配对标识，并仅为永久授权保存原先选择的权限及授权意愿标识；不保存原始客户端凭据或页面令牌。本机与中继服务只持久保存配对公钥、客户端凭据哈希及撤销状态，活跃会话、请求和结果只在内存，不保存画布文件或记录内容、凭据。线上内容仍会经过 HTTPS 中继和 AI 客户端，AI 服务后续的数据处理由客户端决定。原点本身不调用模型。接口、配置与限制见 [MCP 接入指南](docs/mcp.md)，实际验证范围见 [部署说明](docs/deployment.md)。

## 保存与备份

固定使用同一浏览器、配置及 `http://127.0.0.1:4176/`，才能继续访问原来的站点存储。换浏览器、换机器或清理站点数据前，请从“文件”导出 JSON。浏览器自动保存不等于文件备份。

导出当前画布或备份全部画布会直接下载文件。导入时选择 JSON，在同一菜单中查看文件名、将追加的画布数量与各画布卡片数量，再点“追加导入”；已有内容保留。无效文件、超大文件或超出画布容量时显示错误并禁止确认。可重新选择文件，或点“取消”；按 Esc、点菜单外或切换画布也会放弃候选。导入确认前不会改变工作区。

[旧版六步工具](http://127.0.0.1:4176/guided.html)继续保留，数据与自由画布分开；两版 JSON 不自动互转。存储键、格式和恢复机制见 [数据约定](docs/data-format.md)。个人备份可放 `backups/` 或 `private/`，这些目录已从 Git 忽略。
